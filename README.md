# Lumen — Focus Timer Landing Page

A responsive, single-page marketing site for a fictional focus-timer product. Built to demonstrate clean front-end work: distinctive typography, smooth load animations, and a fully responsive layout — no frameworks, no build step.

## 🔗 Live Demo
> https://lumen-stacklane.netlify.app

## ✨ Features
- Fully responsive (mobile → desktop)
- Staggered entrance animations using pure CSS
- Custom design system with CSS variables
- Distinctive type pairing (Fraunces + Spline Sans Mono)
- Zero dependencies — single `index.html` file
- Lighthouse-friendly: fast, accessible, no heavy assets

## 🛠️ Tech
HTML5 · CSS3 (custom properties, grid, keyframe animation) · Google Fonts

## 🚀 Run locally
Just open `index.html` in any browser. That's it.

```bash
# or serve it
python3 -m http.server 8000
# then visit http://localhost:8000
```
